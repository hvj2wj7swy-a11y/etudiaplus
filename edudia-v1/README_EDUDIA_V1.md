# Étudia+ v1

Prototype frontend React + Vite avec données locales.

## Installation

```bash
cd edudia-v1
npm install
npm run dev
```

## Pages

- Accueil
- Connexion / Inscription
- Tableau de bord
- Documents
- Forum

## Structure

- `src/App.jsx`
- `src/components/Navigation.jsx`
- `src/components/Footer.jsx`
- `src/context/AuthContext.jsx`
- `src/pages/*`
- `src/data/mockData.js`
