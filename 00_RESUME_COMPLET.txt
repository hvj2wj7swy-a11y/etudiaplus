🚀 DÉMARRAGE RAPIDE
═══════════════════════════════════════════════════════════════════════════════

ÉTAPE 1: Configuration Base de Données (PostgreSQL)
─────────────────────────────────────────────────────

# Ouvrir terminal et exécuter:
sudo -u postgres psql

# Dans PostgreSQL, exécuter:
CREATE DATABASE edudia_db;
CREATE USER edudia_user WITH PASSWORD 'password123';
ALTER ROLE edudia_user SET client_encoding TO 'utf8';
ALTER ROLE edudia_user SET default_transaction_isolation TO 'read committed';
GRANT ALL PRIVILEGES ON DATABASE edudia_db TO edudia_user;
\q

# Importer le schéma:
psql -U edudia_user -d edudia_db < database/schema.sql


ÉTAPE 2: Configuration Backend
──────────────────────────────

cd backend
cp .env.example .env

# Éditer .env avec vos paramètres PostgreSQL
# Puis:
npm install
npm run dev


ÉTAPE 3: Configuration Frontend
───────────────────────────────

cd ../frontend
cp .env.example .env
npm install
npm start


✅ Terminé! Votre application est prête:
   • Backend:  http://localhost:5000
   • Frontend: http://localhost:3000

💻 API REST - PRINCIPAUX ENDPOINTS
═══════════════════════════════════════════════════════════════════════════════

Authentification:
   POST   /api/auth/register       → Inscription
   POST   /api/auth/login          → Connexion
   GET    /api/auth/verify         → Vérifier token

Utilisateurs:
   GET    /api/users/profile       → Profil utilisateur
   PUT    /api/users/profile       → Mettre à jour profil
   GET    /api/users/top-contributors → Meilleurs contributeurs

Documents:
   POST   /api/documents/upload    → Téléverser document
   GET    /api/documents           → Lister documents
   GET    /api/documents/:id       → Détails document
   POST   /api/documents/:id/rate  → Noter document
   POST   /api/documents/:id/report → Signaler document

Forum:
   POST   /api/forum/questions     → Créer question
   GET    /api/forum/questions     → Lister questions
   GET    /api/forum/questions/:id → Détails question
   POST   /api/forum/questions/:id/answers      → Répondre
   GET    /api/forum/questions/:id/answers      → Lister réponses
   POST   /api/forum/answers/:id/vote           → Voter
   POST   /api/forum/answers/:id/mark-solution  → Marquer solution

Tableau de bord:
   GET    /api/dashboard           → Données tableau de bord
   GET    /api/dashboard/statistics/:userId → Stats utilisateur

Voir API_DOCUMENTATION.md pour la documentation complète!
