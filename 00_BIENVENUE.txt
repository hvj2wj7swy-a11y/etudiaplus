🚀 DÉMARRAGE EN 3 ÉTAPES:

1️⃣  CONFIGURER LA BASE DE DONNÉES (PostgreSQL)
   psql -U postgres
   CREATE DATABASE edudia_db;
   CREATE USER edudia_user WITH PASSWORD 'password123';
   GRANT ALL PRIVILEGES ON DATABASE edudia_db TO edudia_user;
   \q
   psql -U edudia_user -d edudia_db < database/schema.sql

2️⃣  DÉMARRER LE BACKEND (Terminal 1)
   cd backend
   cp .env.example .env
   # Éditer .env avec vos paramètres
   npm install
   npm run dev

3️⃣  DÉMARRER LE FRONTEND (Terminal 2)
   cd frontend
   cp .env.example .env
   npm install
   npm start

✨ Voilà! Votre application est prête: http://localhost:3000

🔌 API ENDPOINTS (20+)

Authentification:
   POST   /api/auth/register
   POST   /api/auth/login
   GET    /api/auth/verify

Utilisateurs:
   GET    /api/users/profile
   PUT    /api/users/profile
   GET    /api/users/top-contributors

Documents:
   POST   /api/documents/upload
   GET    /api/documents
   GET    /api/documents/:id
   POST   /api/documents/:id/rate

Forum:
   POST   /api/forum/questions
   GET    /api/forum/questions
   POST   /api/forum/questions/:id/answers
   POST   /api/forum/answers/:id/vote

Dashboard:
   GET    /api/dashboard
   GET    /api/dashboard/statistics/:userId
