# Guide d'utilisation - Étudia+

## Pour les étudiants

### 1. Créer un compte

1. Allez sur la page d'inscription
2. Remplissez vos informations:
   - Prénom et nom
   - Email
   - Mot de passe (min 6 caractères)
   - Établissement (optionnel)
   - Programme d'études (optionnel)
   - Session (optionnel)
3. Cliquez sur "S'inscrire"

### 2. Se connecter

1. Allez sur la page de connexion
2. Entrez votre email et mot de passe
3. Cliquez sur "Se connecter"

### 3. Accéder au tableau de bord

Une fois connecté, vous accédez à votre tableau de bord qui affiche:
- Vos statistiques personnelles
- Documents récemment ajoutés
- Questions récentes du forum
- Meilleurs contributeurs de la semaine

### 4. Parcourir la bibliothèque de documents

1. Allez dans la section "Documents"
2. Utilisez les filtres pour rechercher:
   - Par mot-clé (titre, description)
   - Par programme d'études
   - Par cours
3. Cliquez sur un document pour voir les détails
4. Téléchargez le document en cliquant sur "Télécharger"
5. Laissez une évaluation (1-5 étoiles)

### 5. Téléverser un document

1. Cliquez sur "Téléverser" dans la navigation
2. Remplissez les informations:
   - **Titre**: Nom du document (ex: "Notes de Calcul 101")
   - **Description**: Résumé du contenu (optionnel)
   - **Établissement**: Votre école/université
   - **Programme**: Votre programme d'études
   - **Code du cours**: Code officiel (ex: "IFT1025")
   - **Nom du cours**: Nom du cours (optionnel)
   - **Fichier**: Sélectionnez le document (PDF, Word, PowerPoint)
3. Cliquez sur "Téléverser le document"

**Points importants:**
- Maximum 10MB par fichier
- Formats acceptés: PDF, Word (.doc, .docx), PowerPoint (.ppt, .pptx)
- Votre document sera vérifié avant publication
- Vous gagnez 10 points pour chaque document approuvé

### 6. Utiliser le forum

#### Poser une question

1. Allez dans la section "Forum"
2. Cliquez sur "Poser une question"
3. Remplissez:
   - **Titre**: Question claire et concise
   - **Contenu**: Détails et contexte
   - **Catégorie**: Domaine d'études
4. Cliquez sur "Poster la question"

#### Répondre à une question

1. Allez dans la section "Forum"
2. Trouvez une question qui vous intéresse
3. Cliquez sur la question pour l'ouvrir
4. Écrivez votre réponse dans le formulaire
5. Cliquez sur "Publier la réponse"

#### Voter sur les réponses

- Cliquez sur 👍 pour voter positif (réponse utile)
- Cliquez sur 👎 pour voter négatif
- La réponse avec le plus de votes positifs s'affiche en haut

### 7. Gérer votre profil

1. Cliquez sur votre nom en haut à droite
2. Cliquez sur "Mon profil"
3. Mettez à jour vos informations
4. Cliquez sur "Enregistrer les modifications"

### 8. Signaler du contenu inapproprié

Si vous trouvez un document ou une réponse inappropriée:

1. Cliquez sur le bouton "..." (plus d'options)
2. Sélectionnez "Signaler"
3. Choisissez la raison
4. Ajoutez une description (optionnel)
5. Cliquez sur "Envoyer"

## Système de points

- ➕ **+10 points**: Pour chaque document approuvé
- ➕ **+5 points**: Pour chaque réponse marquée comme utile
- ➕ **+2 points**: Pour participer au forum
- ➖ **-5 points**: Pour contenu inapproprié signalé
- 🏆 **Badges**: Déblocqués à certains jalons (100 pts, 500 pts, etc.)

## Meilleurs contributeurs

Le classement mensuel récompense les utilisateurs qui:
- Téléversent le plus de documents
- Gagnent le plus de points
- Obtiennent les meilleures évaluations

Consultez le classement sur le tableau de bord!

## Règles communautaires

### À faire ✅

- Partagez des documents de qualité
- Soyez respectueux dans vos réponses
- Aidez les autres étudiants
- Vérifiez les orthographes et grammaire
- Téléversez vos propres documents

### À ne pas faire ❌

- Téléverser du contenu offensant ou discriminatoire
- Plagier ou téléverser du contenu protégé par des droits d'auteur
- Spammer le forum ou envoyer des messages publicitaires
- Utiliser plusieurs comptes pour frauder
- Téléverser des fichiers malveillants

## Dépannage

### Je n'arrive pas à me connecter

- Vérifiez votre email et mot de passe
- Réinitialisez votre mot de passe si nécessaire
- Vérifiez que JavaScript est activé dans votre navigateur

### Mon téléversement a échoué

- Vérifiez la taille du fichier (max 10MB)
- Vérifiez le format (PDF, Word, PowerPoint)
- Assurez-vous que tous les champs requis sont remplis
- Essayez à nouveau en actualisant la page

### Je ne vois pas mes documents

- Vos documents peuvent être en attente de modération
- Allez à "Mon profil" pour voir le statut
- Les documents approuvés apparaissent après quelques heures

### J'ai oublié mon mot de passe

- Cliquez sur "Mot de passe oublié?" sur la page de connexion
- Entrez votre email
- Suivez les instructions envoyées par email

## Conseils pour avoir plus de points

1. **Téléversez des documents de qualité**
   - Assurez-vous que les documents sont clairs et utiles
   - Incluez une bonne description

2. **Participez au forum**
   - Répondez aux questions que vous maîtrisez
   - Soyez précis et constructif

3. **Aidez les autres**
   - Partagez vos connaissances
   - Donnez des explications claires

4. **Maintenez une bonne réputation**
   - Évitez les signalements
   - Restez respectueux
